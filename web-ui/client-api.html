GET/api/v1/healthPublic health check

Verify the service is reachable. No auth required.

GET/api/v1/accountAccount info & usage

Returns your email, API key, and message statistics.

curl -H "x-api-key: sk_..." https://your-server/api/v1/account
GET/api/v1/devicesList gateway devices

List your Android gateway devices with online status, SIM info, and routing config.

POST/api/v1/messagesSend a message / OTP

Send one SMS. If deviceId is omitted the server picks an online device automatically.

curl -X POST https://your-server/api/v1/messages \
  -H "x-api-key: sk_..." \
  -H "Content-Type: application/json" \
  -d '{"to":"+15551234567","message":"Your code is 4821"}'
{ "data": { "id":"7649d22f-...", "status":"pending", "deviceId":"7600e7b2-...", "to":"+15551234567", "message":"Your code is 4821" } }
POST/api/v1/messages/batchSend many at once

Batch send. Accepts { messages: [{ to, message }] } or { recipients: ["+1...","+2..."], message: "..." }.

Quick start (JavaScript)

const res = await fetch("https://your-server/api/v1/messages", {
  method: "POST",
  headers: { "x-api-key": "sk_your_key", "Content-Type": "application/json" },
  body: JSON.stringify({ to: "+15551234567", message: "Your code is 4821" }),
});
const { data } = await res.json();
console.log(data.id, data.status); // "7649d22f-..." "pending"

// poll for delivery
const status = await fetch(`https://your-server/api/v1/messages/${data.id}`, {
  headers: { "x-api-key": "sk_your_key" },
}).then(r => r.json());
console.log(status.data.status); // "delivered"
